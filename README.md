# CRM

CRM-система с таск-трекером и мессенджером для небольшой команды (5 человек): Rust (axum + SQLite) + Tauri + React.

- [Техническое задание v2](docs/TZ.md)
- [Замечания к исходному ТЗ](docs/REVIEW.md)

## Состояние

Первая версия по ТЗ (без 2FA — она во второй версии):

- [x] `crm-core` — бизнес-правила: индикатор дедлайна, рабочее время и тихие часы, расписание напоминаний, ротация бэкапов, оценка диска
- [x] `crm-server` — конфиг, SQLite (WAL) с миграциями, `/api/health`
- [x] вход: первый владелец (только с машины хоста), приглашения сотрудников, логин, сессии, выход, отзыв сессий, сброс доступа, защита от подбора пароля
- [x] HTTPS: собственный CA сервера, сертификат на все адреса ПК, автоперевыпуск при смене IP, `/api/tls/ca` для браузера
- [x] служба Windows «CRM Server» (`crm-server service install|uninstall|start|stop|restart|status`), unit для systemd
- [x] `crm-desktop` (Tauri): приложение в трее, мастер первого запуска (установка сервера, создание владельца), панель состояния
- [x] установщик для Windows `CRM_x.y.z_x64-setup.exe` — собирается в CI, прикладывается к релизу по тегу `vX.Y.Z`
- [x] веб-интерфейс: вход, приглашение, админ-панель владельца (сотрудники, активные входы, сервер и адреса, хранилище и резервные копии)
- [x] резервное копирование: расписание и сроки хранения выбирает владелец, проверка целостности, zstd, ротация, выбор папок, перенос данных
- [x] справка в программе: «Справка» для всех и «Инструкция администратора» только для владельца
- [x] подключение из программы по ключу `CRM1-…` (PIN, Argon2id + XChaCha20-Poly1305), «Мои серверы» со статусом, туннель с закреплённым CA (`crm-connect`)
- [x] клиенты (описание, теги, группы, корзина), задачи (дерево, этапы, приоритеты, сроки, канбан, архив), чат задачи, мессенджер, непрочитанные у каждого свои
- [x] права: владелец / руководитель (свои группы) / сотрудник (свои задачи), одно место решения — `crm_core::access`
- [x] WebSocket-обновления, напоминания с тихими часами, колокольчик и уведомления Windows, поиск Ctrl+K (FTS5)
- [x] вложения (sha256, до 100 МБ), импорт клиентов из Excel/CSV с дублями и отменой, выгрузки, полная выгрузка ZIP
- [x] восстановление из копии в один клик, пакет переезда `.crmpack`, `crm-server restore`
- [x] VPN WireGuard из админ-панели (ключи, QR, отзыв) + `crm-server service vpn-apply` из трея
- [x] прогноз и тревоги по диску, проверка обновлений, мобильная вёрстка
- [ ] вторая версия: 2FA, гибкие права, шифрование копий и копия в облако, подпись установщика

## Запуск для разработки

Нужен Rust (stable).

```sh
cargo test --workspace          # все тесты
cargo run -p crm-server -- --config dev.toml
```

Сервер по умолчанию слушает `0.0.0.0:8443` по HTTPS. При первом запуске в папке данных создаётся `tls/ca.crt` — сертификат, которому доверяют клиенты. Без HTTPS сервер разрешено запускать только на `127.0.0.1`. Первый владелец создаётся запросом с этой же машины:

```sh
curl -H 'content-type: application/json' \
  -d '{"username":"owner","display_name":"Владелец","password":"очень-надёжный-пароль"}' \
  --cacert .dev/data/tls/ca.crt https://localhost:8443/api/setup
```

Пример `dev.toml`:

```toml
listen = "127.0.0.1:8443"

# [tls]
# enabled = false   # только для 127.0.0.1

[storage]
db_dir = "./.dev/data"
attachments_dir = "./.dev/attachments"
backup_dirs = ["./.dev/backups"]
```

Проверка: `curl --cacert .dev/data/tls/ca.crt https://localhost:8443/api/health` → `{"status":"ok","version":"0.1.0"}`.

## Установка на Windows

1. Скачайте `CRM_…_x64-setup.exe` из раздела [Releases](https://github.com/kclazzy/crm/releases) (или из артефакта `CRM-Setup` последней сборки CI).
2. Запустите установщик. Пока он не подписан сертификатом, Windows может показать «Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае».
3. Откройте CRM → «Этот компьютер — сервер» → подтвердите запрос администратора → создайте владельца.
4. Окно можно закрыть: CRM останется в трее, сервер работает службой и стартует вместе с Windows.

## Структура

```
crates/crm-core     доменные типы и чистые бизнес-правила (без I/O)
crates/crm-server   axum API, SQLite, HTTPS, служба Windows
crates/crm-connect  подключение сотрудника: ключ, «Мои серверы», статус, туннель с закреплённым CA
crates/crm-desktop  приложение в трее (Tauri) и установщик NSIS
packaging/linux     unit systemd
migrations/         схема БД (единственный источник правды)
docs/               ТЗ и ревью
```

## Сборка установщика на своём компьютере

На Windows 10/11, один раз поставьте инструменты (PowerShell):

```powershell
winget install Git.Git Rustlang.Rustup OpenJS.NodeJS.LTS
winget install Microsoft.VisualStudio.2022.BuildTools --override "--wait --passive --add Microsoft.VisualStudio.Workload.VCTools --includeRecommended"
```

Перезапустите PowerShell, затем в папке проекта:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build-windows.ps1
```

Установщик появится в `target\release\bundle\nsis\CRM_…_x64-setup.exe`. Первая сборка — 20–40 минут, следующие — несколько минут.
