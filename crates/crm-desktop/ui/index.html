Адрес для сотрудников

    Работает в локальной сети офиса. Для работы из дома понадобится VPN, например Tailscale.

    Отпечаток сертификата

    — Сотрудник сверяет его при первом подключении — так он убедится, что подключается именно к вашему серверу.

    Сервер остановлен
