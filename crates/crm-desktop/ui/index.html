Этот компьютер — сервер

Здесь будут храниться клиенты, задачи и переписка команды. Компьютер должен быть включён в рабочее время.

Windows один раз попросит разрешение администратора.
💻

Подключиться к серверу

Для сотрудников: вставьте ключ подключения, который прислал владелец.

Сертификаты ставить не нужно — программа сама проверит, что сервер ваш.

Создайте владельца

Владелец управляет сервером, сотрудниками и бэкапами. Это ваша учётная запись.

Сервер работает

Окно можно закрыть — CRM останется в трее, а сервер продолжит работать в фоне.

Адрес для сотрудников

    Работает в локальной сети офиса. Для работы из дома включите доступ через интернет: CRM → Администрирование → Удалённый доступ.

    Отпечаток сертификата

    — Сотрудник сверяет его при первом подключении — так он убедится, что подключается именно к вашему серверу.
